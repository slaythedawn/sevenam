# Angle bank

Backlog of post angles, tagged by pillar, each with a source. An angle without a source
cannot become a post, because guardrail 5 has nothing to check it against.

**Sixty entries minimum. Never below thirty.** The daily Routine counts this file and
warns when it drops.

Format, one per line:

```
- [pillar] the angle in a sentence — source
```

Pillars: model · 7am · ai-tools · creative · craft · personal · buildlog

Filled 29 Aug 2026 from the site's own pages, which are the safest source available:
